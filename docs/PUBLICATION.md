# Publication and validation notes

This is a clean source snapshot, not a fork carrying private commit history.
The private repository and active checkout were not rewritten or made public.

Included: allowlisted committed Swift application source, Xcode metadata,
evidence contracts, selected static checks, and the existing vendored LiteRT-LM
Swift wrapper with its original license. Meta and Liquid SDKs remain package
references, not redistributed SDK downloads. Source hashes are in SNAPSHOT.json.

Excluded: private Git history, raw media, conversations, personal exports,
recordings, model weights, runtime ledgers, device diagnostics, archived
prototypes, and benchmark-result dumps. Meta client token, app ID, signing team,
associated domains and active telemetry endpoints are blank. Developer home paths
and private peer addresses were replaced with examples. Configure your own
authorized registration privately; do not commit it.

Historical development records describe LFM2.5-VL-450M processing selected live
Meta DAT frames on the phone, plus separate controlled replay/routing trials.
These are component results, not proof of an always-working wearable assistant.
The 1.6B vision and Gemma reasoning paths have distinct latency and quality
constraints; do not pool them into one performance claim.

This publication does not perform a fresh phone build, installation, optical HUD
inspection, live DAT session, or complete speech-to-response hardware test.
Missing assets and blank registration intentionally prevent turnkey hardware use.

No license is newly granted to original project code. Third-party notices remain
in place. Public source visibility does not override SDK or model license terms.
